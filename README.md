# Experiment 4 (Load Balancer)

This branch consists of sample code for load balancer over 3 servers in 3 different scenerios.

Main code in ```LoadBalancer.java``` with the tasks in files ```Task{Task_number}.java```.

### Task 1

All the load is assigned to server1 while server2 and server3 is idle.

### Task 2

The load is unevenly distributed over server1 and server2 while server3 is idle.

### Task 3

The load is evenly distributed over the 3 servers (Most Optimal Solution).
