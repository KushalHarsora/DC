# Experiment 2 (Group Communication)

This branch consists of sample code for group communication using open and closed group.

Main Server code in ```BroadcastServer{type_of_communication}.java``` with the Client code in file ```BroadcastClient{type_of_communication}.java```.

### Open Communication

ip address is ```255.255.255.255``` to allow everyone to receive the message from server.

### Closed Communication

ip address is ```192.168.5.255``` to allow all devices in subnet for closed group communication.
